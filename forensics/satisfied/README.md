# Satisfied

My friend sent me a save file for a game but never told me what game it was for. I would love to see what is in the world, but unfortunately, I can't figure out what the game is.

## Solution

By looking at the file in notepad I could see multiple things like different games rules such as disabling ArachnidCreatures or the start location of Northern Forest. This along with the name of the challenge being Satisified led me to the conclusion that this was a satisfactory game file. 

I then found this site:
https://satisfactory-calculator.com/en/interactive-map

I loaded the file into that site and saw the flag on the map.
